# Security Policy

## Reporting a vulnerability

Please do not open a public issue for credentials, tokens, private logs, or a
reproducible security vulnerability. Use GitHub's private vulnerability
reporting feature for this repository when it is available.

When reporting, include:

- the affected version or commit;
- a short description of the impact;
- reproducible steps that do not contain secrets; and
- a minimal redacted log or sample response when it is necessary to diagnose
  the issue.

This project must not read, store, or print Codex or ChatGPT access tokens.
